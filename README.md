# 🌍 Schengen Job Search Directory & Application Tracker

An interactive job-search resource designed to help international job seekers discover employment opportunities across the **29 countries in the Schengen Area**, with a focus on English-speaking roles, visa sponsorship and international recruitment.

The project brings together job boards, country-specific employment resources, immigration guidance and application-tracking tools in one place.

## 🎯 Project Overview

Searching for jobs abroad can be challenging. Job seekers often have to navigate dozens of employment websites, understand unfamiliar work-permit systems and identify employers willing to hire international candidates.

This project aims to simplify that process through a centralised job-search directory available in both an interactive HTML interface and an Excel workbook.

## ✨ Key Features

- **29-country directory:** Explore employment resources across the Schengen Area.
- **Curated job boards:** Access general job portals, country-specific recruitment websites and specialist career platforms.
- **English-language opportunities:** Identify resources useful for finding English-speaking roles.
- **Visa sponsorship research:** Find official immigration resources and guidance for checking employer sponsorship eligibility.
- **Interactive job search:** Search and filter resources by country, region and category.
- **Application tracking:** Organise applications and monitor recruitment progress using the Excel workbook.
- **Direct links:** Open job boards, employer career pages and official immigration websites.
- **Copy-ready search queries:** Use targeted search terms to discover relevant international vacancies.
- **Design and technology focus:** Include resources relevant to product design, UI/UX, game development, 3D art, visual design and analytics.

## 🚀 How to Use

### Option 1: Interactive HTML Directory

1. Download `schengen_job_directory_interactive.html`.
2. Open the file in a modern web browser.
3. Search and filter job resources by country or category.
4. Open relevant job boards and review their vacancies.
5. Verify the employer's work-authorisation and sponsorship requirements before applying.

### Option 2: Excel Workbook

1. Download `schengen_job_search_directory.xlsx`.
2. Open it in Microsoft Excel or a compatible spreadsheet application.
3. Browse the country directory and job-board links.
4. Record relevant vacancies in the application tracker.
5. Update application statuses and follow-up information as your search progresses.

## 🛂 Important Immigration Disclaimer

An English-language job advertisement does not automatically mean that visa sponsorship is available.

Employment eligibility depends on the employer, the position, the applicant's qualifications and the destination country's immigration rules. Some permits require specific salary thresholds, recognised sponsors or additional eligibility criteria.

The Schengen Area does not provide a single work permit that authorises employment in every member country. Always consult official national immigration sources and verify the requirements for your individual circumstances.

Job listings, website availability and immigration requirements may change over time. Check original sources before making application or relocation decisions.
